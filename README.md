# تمرین ششم: FCFS با Dekker، Peterson، Semaphore و Monitor

الگوریتم اصلی پروژه‌های قبلی شما **FCFS** است. این پروژه ترتیب ورود FCFS را حفظ می‌کند و چهار روش همگام‌سازی را برای محافظت از بخش بحرانی مقایسه می‌کند.

- **Dekker:** الگوریتم نرم‌افزاری انحصار متقابل برای دو thread.
- **Peterson:** الگوریتم نرم‌افزاری ساده‌تر برای دو thread.
- **Semaphore:** سمافور دودویی برای کنترل ورود.
- **Monitor:** مانیتور با قفل و شرط انتظار.

**تفاوت مفهومی:** FCFS سیاست زمان‌بندی است؛ Dekker و Peterson الگوریتم‌های انحصار متقابل‌اند و Semaphore و Monitor سازوکارهای همگام‌سازی. بنابراین پروژه ترتیب FCFS را ثابت می‌کند و روش حفاظت از منبع مشترک را مقایسه می‌کند.

## اجرا
Python 3.8+ لازم است؛ کتابخانه خارجی نیاز نیست:
```bash
python src/fcfs_sync_comparison.py
```
خروجی در ترمینال و `results/comparison.csv` ذخیره می‌شود.

محدودیت: Dekker و Peterson در کاربرد کلاسیک برای دو thread هستند. این پروژه شبیه‌سازی آموزشی است و زمان‌ها به سیستم‌عامل و مدل حافظه وابسته‌اند.
